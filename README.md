# Markd

**Markd** is a context-driven knowledge bookmarking platform designed to solve the *"save and forget"* problem.

Traditional bookmarks store links but lose context. Over time, collections become cluttered, difficult to search, and rarely revisited. Markd aims to transform bookmarks into searchable, actionable knowledge by capturing intent, improving discoverability, and surfacing what is genuinely useful.

## Core Ideas

* Save resources with context, not just URLs
* Replace folder complexity with lightweight tagging
* Search by memory, intent, and notes
* Track usage to identify valuable resources
* Make forgotten bookmarks visible and manageable

## Status

🚧 **Currently under development**

Markd is in the MVP development phase. Features and workflows are actively being implemented and refined.
